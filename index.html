Sync einrichten

Sync deine Boards zwischen iPad und PC über deine eigene Firebase-Datenbank — kostenlos, deine Daten, niemand sonst kommt ran.

📋 Einrichtungs-Schritte (einmal, ca. 2 Minuten)
  1. Öffne console.firebase.google.com und logg dich mit Google ein.
  2. Klick „Projekt hinzufügen" → Name vergeben (z.B. „mein-whiteboard") → Erstellen. Analytics kannst du aus lassen.
  3. Im Projekt links auf „Realtime Database" → „Datenbank erstellen" → Region wählen (Europa) → „Im Testmodus starten" → Aktivieren.
  4. Oben links auf das ⚙ (Zahnrad) → Projekteinstellungen → unten bei „Deine Apps" auf das </>-Symbol klicken (Web-App).
  5. Beliebigen App-Namen eingeben → Registrieren. Hosting nicht aktivieren.
  6. Die gezeigte firebaseConfig kopieren (das ganze JS-Objekt zwischen { ... }) und unten einfügen.

⚠ Wichtig: Die Config muss databaseURL enthalten. Falls nicht: in Firebase die Realtime Database erst aktivieren.

Auf einem Gerät generieren, kopieren, auf dem anderen Gerät einfügen. Wer den Code hat, sieht die Boards — also nicht weitergeben.
